# Restaurant Rating Analysis Dashboard

## Project Overview
This project is an end-to-end Power BI dashboard that analyzes restaurant ratings, customer satisfaction, pricing, and dining behavior using interactive visualizations.

## Tools Used
- Power BI
- Power Query
- DAX
- Microsoft Excel

## Key KPIs
- Total Restaurants
- Average Rating
- Average Cost for Two
- Online Delivery Restaurants
- Offline Delivery Restaurants
- Excellent & Poor Restaurants
- Total Revenue

## Dashboard Insights
- Restaurant performance by area
- Customer satisfaction analysis
- Online order vs table booking trends
- Average cost distribution
- Area-wise rating comparison
